隱私權政策

適用對象：智慧助理（Google OAuth 用戶端）｜生效日期：2026-10-13

智慧助理是一套安裝在單一台 Mac mini 上、供特定使用者個人使用的本機助理。使用者透過 Telegram 對助理下指令，由這台電腦上的本機語言模型處理。本政策說明本應用程式透過 Google API 取得哪些資料、如何使用與保存，以及如何撤銷授權。

一、我們向 Google 要求的權限

只要求一項權限：https://www.googleapis.com/auth/calendar.events（檢視及編輯使用者有權存取之 Google 日曆中的活動）。不要求 Gmail、雲端硬碟、聯絡人或其他 Google 資料的權限。

二、資料的使用方式

  • 只有在使用者明確下指令時，才會查詢、搜尋、建立、修改或移除使用者自己的日曆活動。
  • 不會新增受邀者，也不會寄出邀請信。
  • 取得的活動內容只用於回答使用者當次的要求，例如列出行程、檢查時間衝突、整理會議準備資料。
  • 不用於廣告、不出售、不提供給第三方，也不用來訓練或改良任何人工智慧模型。

三、資料流向與保存

  • 處理地點：活動資料由這台 Mac mini 上的本機語言模型處理，不會送到任何雲端 AI 服務。
  • Telegram：使用者的提問與助理的回覆（可能包含活動標題、時間等）會經由 Telegram 傳送，適用 Telegram 的隱私權政策。
  • 本機紀錄：對話紀錄（包含助理讀到的活動內容）保存在這台電腦的本機資料庫，供後續對話參考；不會上傳到其他伺服器。
  • 授權憑證：Google 發出的 OAuth 權杖只存在這台電腦上、僅限本機帳號讀取的檔案中，不進入版本控制、日誌或訊息。

四、遵循 Google API 服務使用者資料政策

本應用程式對於從 Google API 取得之資料的使用與傳輸，遵循 Google API 服務使用者資料政策，包括其中的「限制使用」（Limited Use）規定。

五、撤銷授權與刪除資料

  • 使用者可隨時到 Google 帳戶的「第三方應用程式與服務」 移除本應用程式的存取權。撤銷後助理會回報需要重新授權，不會再存取日曆。
  • 也可請維運者刪除本機的權杖檔與對話紀錄。
